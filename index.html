notesd

Tiny git-backed notes/paste server in Go. Every write is a commit; you get history for free.

Source on GitHub →

Web interface

Open any URL in a browser and notesd serves a small HTML editor — create, view, and edit notes without curl. GET /$ID shows the current content (or an empty editor for a new id), GET /$ID/history lists revisions with previews, and GET / is a browsable index of all notes.

API

URL=http://localhost:3333

curl -X POST   -d "..." "$URL"               # auto id (<unix>-<rand>)
curl -X POST   -d "..." "$URL/$ID"           # create or overwrite
curl    "$URL/$ID"                           # latest content
curl    "$URL/$ID?version=<sha>"             # content at commit (prefix ok)
curl    "$URL/$ID/history"                   # <sha> <unix-time> <preview>
curl -X DELETE "$URL/$ID"                    # delete (history preserved)
curl    "$URL"                               # list: <id>\t<preview>

PUT is an alias for POST. Writes return the commit SHA in X-Commit. Send Accept: application/json on GET / for JSON. Browsers get a small editor UI.

Config

Configurable via CLI flags or env vars (flags override env). Run notesd --help for the full listing.

  • -port / PORT (default 3333) — TCP port to listen on
  • -storage / STORAGE_PATH (default data) — git-backed storage dir (auto-init)
  • -git-remote / GIT_REMOTE (optional) — pull --ff-only before each request, push async after commit
  • --version — print version and exit

Install

With go install:

go install github.com/cstml/notesd@latest
notesd --help

As a container:

docker build -t notesd .
docker run -d --name notesd -p 3333:3333 -v notesd-data:/data notesd
# or: docker compose up -d

As a systemd service (from source):

make build
sudo make install   # binary + systemd unit
sudo make enable
